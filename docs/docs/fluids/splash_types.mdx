---
title: Splash Types
---

Splash Types allow for customizing the splash effects from mobs/players falling in a fluid. However creating a splash
type is not enough for it to work it must be added to a [Fluid Definition](fluid_definitions).

Create a new JSON file in the `assets/{namespace}/subtle_effects/fluid_definitions` folder of a resource pack.

| Name             | Required | Description |
|------------------|----|------------------|
| `splash`         | No | A [Splash Options](#splash-options) object |
| `splash_overlay` | No | Either a boolean or a [Splash Options](#splash-options) object. If true splashes will have an overlay using default values, if false splashes won't have an overlay |
| `splash_ripple`  | No | A [Splash Options](#splash-options) object used to customize ripple ring around the point of impact of the fluid |
| `droplets`       | No | [Droplet Options](droplet_options) object. If omitted, the droplet options will be gotten from the [Fluid Definition](fluid-definitions) that spawned splash particle |

## Splash Options

| Name           | Required | Description |
|----------------|----|------------------|
| `sprite_set`   | No | String ID of a particle definition. <br/> The ID for a particle definition is the namespace defining it followed by the path relative to the `/particles` folder. For example, the path for the flame particle is: `assets/minecraft/particles/flame.json` and it's ID is: `minecraft:flame`. For a particle definition in a subfolder e.g. `assets/examplepack/particles/example_path/example.json` the ID would be: `examplepack:example_path/example` |
| `color`        | No | A [Color Provider]($color_providers) used to determine a particle's color |
| `tinting`      | No | An object containing either a float from 0 to 1 defined as `"intensity"`, which will change the strength that the `color` is applied to the particle, or a boolean defined as "use_config", which will use the value of the `Entities > Splashes > Splash Overlay Tint` config |
| `transparency` | No | An object containing either a float from 0 to 1 defined as `"alpha"`, or a boolean defined as `"use_config"`, which will use the value of the `Entities > Splashes > Splash Overlay Alpha` config |

----

**Splash Type for lava**
```json
{
  "splash": {
    "sprite_set": "subtle_effects:lava_splash"
  },
  "splash_ripple": {
    "sprite_set": "subtle_effects:lava_splash_ripple"
  }
}
```

**Splash Type for water**
```json
{
  "splash": {
    "color": {
      "type": "subtle_effects:biome_color",
      "color_type": "water_color"
    }
  },
  "splash_overlay": {
    "color": {
      "type": "subtle_effects:biome_color",
      "color_type": "water_color"
    },
    "tinting": {
      "use_config": true
    },
    "transparency": {
      "use_config": true
    }
  },
  "splash_ripple": {
    "color": {
      "type": "subtle_effects:biome_color",
      "color_type": "water_color"
    },
    "tinting": {
      "use_config": true
    },
    "transparency": {
      "use_config": true
    }
  },
  "droplets": {
    "color": {
      "type": "subtle_effects:biome_color",
      "color_type": "water_color"
    },
    "tinting": {
      "use_config": true
    },
    "land_particle": "minecraft:splash"
  }
}
```
